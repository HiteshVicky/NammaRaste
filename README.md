# NammaRaste 🚧

NammaRaste is an Android application developed using Kotlin in Android Studio for reporting civic issues such as potholes, damaged roads, garbage problems, and non-working street lights.

## Features

- User Signup and Login
- Room Database Integration
- Capture and Submit Issue Photos
- Pothole and Street Light Reporting
- Complaint Tracking ID Generation
- Complaint Status Tracking
- Mobile Camera Integration
- Simple and User-Friendly Interface

## Technologies Used

- Kotlin
- Android Studio
- Room Database
- XML Layouts
- Camera Intent
- Git & GitHub

## Project Workflow

1. User signs up
2. User logs in
3. User captures issue image
4. Complaint is submitted
5. Tracking ID is generated
6. User can track complaint status
